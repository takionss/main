# SmilesLife Website Project

이 프로젝트는 알툴즈 스타일의 기업형 홈페이지입니다.

## 프로젝트 정보
- **GitHub 주소**: [takionss.github.io/main](https://takionss.github.io/main)
- **커스텀 도메인**: [smileslife.co.kr](http://smileslife.co.kr)

## 기술 스택
- HTML5
- Tailwind CSS (CDN)
- Font Awesome (Icons)

## 배포 방법
1. GitHub에서 `main` 이라는 이름의 새 레퍼지토리를 생성합니다.
2. 이 폴더의 파일들을 업로드합니다.
3. GitHub Settings -> Pages에서 도메인을 `smileslife.co.kr`로 설정합니다.
